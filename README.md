# Sentiment Analysis using Python

## Description
A simple machine learning project that classifies customer reviews
as positive or negative.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression

## Machine Learning
- Text Classification
- TF-IDF Feature Extraction
- Logistic Regression
- Train-Test Split
- Model Evaluation

## Dataset
The project uses customer product reviews with positive and negative
sentiment labels.

## Result
The model achieved approximately 66.67% accuracy on the test data.
